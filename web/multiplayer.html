Uma sala. Dois jogadores.

Jogar pela internet

  1. Abra o aplicativo Windows ou o jogo no navegador.
  2. Escolha Multiplayer online, sua facção e o endereço do servidor de partidas.
  3. Combine um código de sala com o outro jogador. Ambos devem usar o mesmo servidor e código.
  4. O primeiro jogador escolhe o mapa. A partida começa quando o segundo entra.

No site HTTPS, use um endereço wss://. O aplicativo e o navegador podem entrar na mesma sala. Os gráficos e arquivos do jogo rodam em cada computador; a conexão compartilha comandos e atualizações da partida.

Jogar na mesma rede

O aplicativo Windows já inicia um servidor na porta 48777. O anfitrião usa ws://127.0.0.1:48777/multiplayer. O outro computador usa ws://IP-DO-ANFITRIÃO:48777/multiplayer. Também é possível abrir http://IP-DO-ANFITRIÃO:48777/ no navegador da rede local. Se o Windows solicitar acesso à rede, permita apenas na rede em que pretende jogar.

Sobre o servidor

O site pode ficar no GitHub Pages. O servidor de partidas precisa de uma hospedagem que execute Node.js ou do computador anfitrião com acesso público configurado. Criar o repositório sozinho não coloca o servidor online.

Esta versão é para partidas casuais: o primeiro jogador mantém a simulação e o servidor encaminha os comandos. Se alguém sair, a partida é encerrada. Não há reconexão automática, migração de anfitrião nem proteção competitiva contra alterações no jogo.
